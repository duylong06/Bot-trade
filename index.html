Báo đúng giây khi nến đóng

Lịch chạy của GitHub hay bị bỏ hoặc trễ tới cả giờ. Để bot chạy đúng phút 58 mỗi giờ, chờ nến đóng rồi báo ngay trong vài giây, hãy nhờ cron-job.org (miễn phí) gọi bot.

Cách cài — làm một lần
  1. Tạo khoá GitHub. Mở trang tạo token → đặt tên “cron bot” → thời hạn dài nhất → Repository access: Only select repositories → chọn Bot-trade → Permissions → Repository permissions → Actions: Read and write → Generate → sao chép token.
  2. Tạo việc hẹn giờ. Đăng ký cron-job.org → Create cronjob.
  3. Ô URL:
  4. Execution schedule: Every hour, phút 58. Múi giờ để mặc định cũng được.
  5. Tab Advanced → Request method: POST.
  6. Headers — thêm 3 dòng:
    AuthorizationBearer <token vừa tạo>
    Acceptapplication/vnd.github+json
    X-GitHub-Api-Version2022-11-28
  7. Request body:
    {"ref":"main"}
  8. Lưu, rồi bấm Test run: thấy mã 204 là được. Sau đó ô “Tình trạng bot” ở trên sẽ ghi “kích hoạt bởi: hẹn giờ ngoài”.
